# Security policy

Please do not publish credentials, pairing codes, device tokens, player data, private server details, or diagnostic archives in a public issue.

For a suspected security or privacy issue, use the private security-reporting option on this GitHub repository when available. Otherwise contact the Gillions maintainer privately through the support route listed on [gillions.app](https://gillions.app).

Include the affected plugin version, a concise reproduction, and sanitized evidence. Remove account, character, retainer, buyer, filesystem, and network identifiers before sharing logs.
