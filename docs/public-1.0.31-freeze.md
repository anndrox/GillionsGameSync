## Permission and release reconciliation

Both product compilations use the same accepted permissionAuthority revision 1,
30-second lease, ordering/enrollment binding, eight independent decisions and
separate FATE policy. Legacy local OFF remains OFF. Fresh explicit Site ON/OFF
supersedes historical gates without rewriting configuration. Private retention
needed for an explicit personal sync decision is authorized through a live lease
callback, not a cached flag or permanent local preference. Lease loss stops that
authority immediately; local history is preserved. Missing capability/product
acknowledgements suppress sends independently of ordinary sync.

The historical Public build compiled out required capabilities and selected the
older direct xivpf contributor. Public now selects the accepted authenticated
Gillions implementation. Product comparisons, Market payload identity and user
agents use the actual compiled identity, never impersonate Testing. Public
reports four-part `1.0.31.0` consistently with FATE collectorVersion, supported by
the existing Site version parser. Native payload/receipt/permission schemas do
not change. The accepted Site `f3dea3d2` still admits only Testing86/87 FATE and
rejects this Public candidate pending the separate exact-admission handoff.

Independent review corrections bind PF-link acknowledgement to the actual
compiled product and restrict Market negotiation, session capture and dispatch
to the exact shared TEST origin. Production, direct-IP, plaintext and lookalike
origins cannot activate that promoted transport. Historical Market preference
remains ON by default; an unavailable transport is not a consent change.
