# Gillions Game Sync 1.0.30

This update removes venture planning and AutoRetainer integration from Gillions Game Sync while retaining ordinary opt-in synchronization and native Retainer observations.

- Removes AutoRetainer discovery and IPC, venture-plan polling, apply/restore paths and their plugin controls.
- Keeps native Retainer inventory, listings, venture observations/results and exact result acknowledgements under the existing account and product gates.
- Preserves legacy plan backups and ownership records as inert local configuration, including timestamp strings with their original offset and precision. Existing pairing and enabled sync categories are retained.
- Keeps previously cached AutoRetainer stats and venture-start times historical rather than presenting them as fresh observations.

## Updating

Use the existing stable custom repository in Dalamud's plugin installer and update Gillions Game Sync to `1.0.30`. The repository URL is unchanged:

`https://raw.githubusercontent.com/anndrox/GillionsGameSync/main/data/GillionsGameSync.json`

No re-pairing or configuration deletion is required. The old AutoRetainer plan controls will no longer appear after the updated plugin loads.

This update does not cancel plans already installed in AutoRetainer or guarantee cancellation of callbacks queued by an older loaded plugin. Manage external automation through AutoRetainer's own controls when you need it to stop. No automatic restore, cleanup or recovery UI is added.

Local stable/testing builds, synthetic configuration round-trips and independent source reviews support this release; they do not establish live-game or visual acceptance. Public availability and an individual user's installed version are separate states. Retainer uploads continue to require the server's applicable product/contract acceptance.
