# Gillions Game Sync 0.0.114 (Testing)

## What's new

- Choose a vendor, quest, card match or FATE place on Gillions to flag it on your in-game map.
- Map flags from the site starts On. You can turn it off in Game Sync's General settings or through the Site's device permission.

## Compatibility and acceptance

- Game build 2026.11.03.0000.0000, Dalamud 15.0.4.1 (API 15).
- Site support and admission of this candidate are required.
- In-game TEST acceptance of a flag in another zone is pending through the PP.
