# Gillions Game Sync 0.0.115 (Testing)

## What's new

- A Hunt bill you pick up again with the same order number now starts from its own count. Before, it could keep the earlier bill's kills, so Gillions showed a fresh bill as already done. Once Key Items shows a bill has ended, the next bill of that type takes the game's own counts.
- The October 2026 game builds are no longer listed for any feature. No client can run them since the November update.

## Updating

- Use only one Game Sync channel at a time. This Testing update uses your existing Testing pairing and sharing settings.

## Compatibility and acceptance

- Game build 2026.11.03.0000.0000, Dalamud 15.0.4.1 (API 15).
- Site admission of this version on TEST is required.
- In-game TEST check, through the PP: finish a Hunt bill, pick up the next bill of the same rank, and check that Gillions shows the new bill's own counts.
