# Stable 1.0.31.7: fewer refused requests

Status: **published Stable release**, 2026-10-28. The [immutable GitHub Release](https://github.com/anndrox/GillionsGameSync/releases/tag/v1.0.31.7)
and the existing Stable update feed both verify as 1.0.31.7. Earlier immutable
releases are preserved. This release includes PRs 22, 25 and 29, plus PR 24
release tooling and PR 28 contract data, under the owner's approved scope.
Independent review passed on the exact published head. Site's Production
release 5 admits 1.0.31.7 while retaining 1.0.31.6 and 1.0.31.2; the owner
authorized publication after that admission.

Correction to the request: inventory batching (Testing 0.0.94, at most one
inventory upload per 10 seconds) already shipped in **Stable 1.0.31.6**; see
docs/releases/v1.0.31.6.md, "Less traffic". It is not new in 1.0.31.7.
1.0.31.7 carries the two refusal back-offs and the approved check-in fields proven in Testing since then.

## What a 1.0.31.6 user gets

- The regular check-in now includes the game version and the plugin's eight local settings, so Gillions can show them; nothing else is shared.
- **Character not linked: no retry loop** (Testing 0.0.96, PR #25):
  - If the character you are playing isn't linked to your Gillions account,
    Game Sync waits 5 minutes before uploading again. It no longer retries
    inventory every 10 seconds. On 2026-10-25, Stable 1.0.31.6 made 141 refused
    uploads in one session; that is now at most one every 5 minutes.
  - Switching character or logging in again retries at once. After you link
    the character on Gillions, the next attempt (within 5 minutes, or Sync now)
    succeeds.
  - Nothing is lost: changes keep being observed locally and upload once the
    character is linked.
  - The one-time chat notice names the character and says to link it on
    Gillions or play a linked one.
- **Refused travel upload: 5-minute wait** (Testing 0.0.95, PR #22):
  - Applies only if travel sharing is on. It is off by default.
  - A travel upload that Gillions refuses (for example, a game build it hasn't
    admitted yet) waits 5 minutes instead of retrying every 15 seconds.

## What happens on update

- No re-pairing, no permission prompt, and no setting or consent default
  changes.
- No new data category.
- The only visible change in the plugin is the clearer chat notice.
