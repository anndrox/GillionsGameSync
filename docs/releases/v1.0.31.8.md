# Stable 1.0.31.8: automatic Hunt recovery

Status: **published Stable release**, 2026-10-29. The [immutable GitHub Release](https://github.com/anndrox/GillionsGameSync/releases/tag/v1.0.31.8)
and the existing Stable update feed verify as 1.0.31.8. This release contains the
independently reviewed Hunt recovery source from PR 34 plus release bookkeeping.
Production admits its Hunts and exact October FATE source/epoch, retaining
1.0.31.7 continuity. Installed-device Hunt/FATE syncing remains unverified.

## What a 1.0.31.7 user gets

- With Hunt sharing already allowed, observations previously refused because
  Gillions lacked compatible Hunt support can resume automatically when Gillions
  accepts changed support. Game Sync uses fresh observations and permits one
  recovery attempt for unchanged input; repeated refusals do not create a loop.
- An older check-in reply cannot replace newer permission or support information
  or use that recovery attempt.
- No restart, re-pairing, manual upload, receiver selection or extra setup is
  required. Existing Off choices remain effective. No new data category, reader,
  permission, toggle or consent default is introduced.

## Update and release limits

Existing pairing, local settings and retained history are preserved. Untouched
older Hunt observations retain their original collector version; fresh reads
identify 1.0.31.8. History is not relabeled as a new observation.

The release keeps the existing October game/native qualification and all other
feature implementations. Compatible Site admission preceded publication.
Managed serializer and contract fixtures are not proof of an installed-device
receipt, gameplay or the owner's previous failure state. No Site deployment or
Market operation is included in this publication record.

## Ordinary update

Keep the existing Stable custom repository URL:
`https://raw.githubusercontent.com/anndrox/GillionsGameSync/main/data/GillionsGameSync.json`.
Open Dalamud's plugin installer (`/xlplugins`), check for updates, apply the
Gillions Game Sync Stable update and confirm **1.0.31.8** is installed. Continue
ordinary play with the existing pairing and sharing choices; Off remains Off.
No re-pair, consent change, manual upload, receiver selection, restart workaround
or new toggle is required. Natural installed-device Hunt/FATE syncing remains
unverified until the owner updates and tests it.
