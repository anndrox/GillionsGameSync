# Gillions Game Sync 1.0.31.14 (Stable)

## What's new

- Hunt coverage checks the exact Site item mapping and leaves time for Site to validate each sample. Travel sends its observation time at Site's millisecond precision. A temporary body-read failure can retry within the existing upload limits.
- Game Sync disables redirects and verifies the destination of every device-authenticated request. Stable supports pairing to Gillions Production and TEST.
- Disconnect asks Site to revoke the device. When Site can't confirm revocation, the plugin clears the local pairing and tells you to disconnect the device in Gillions settings.

## Updating

- Existing device credentials migrate to Windows per-user protection. Pairing and sharing choices carry over when the credential is readable by the same Windows user.
- **Rolling back to Stable 1.0.31.13 leaves every migrated player unpaired.** The older plugin can't read the protected credential. Create a fresh pairing code on the Gillions site you use and pair again.
