# Public 1.0.31.6 — 7.57 hotfix compatibility candidate (unpublished)

Status: **Hunt Progress physically accepted** on the hotfix runtime through the Testing
0.0.90 build ([record](testing-0.0.90.md#owner-acceptance-record)). Public is a
separately compiled product, so no Public DLL has run in the game. Nothing is published.

This candidate supersedes the unpublished [Public 1.0.31.5](v1.0.31.5.md). The
`v1.0.31.5` tag and draft release were built from a commit whose CI failed, and
their October qualification no longer matches the release runtime. Leave them
immutable and unpublished.

It carries everything in 1.0.31.5, plus:
- collectible readiness (PR #6);
- the per-collector compatibility table and current-runtime qualification
  described in [Testing 0.0.90](testing-0.0.90.md) and
  [native compatibility](../native-compatibility.md).

Dalamud 15.0.3.9). Published Stable 1.0.31.2 accepts only the September game
build, so it has shown Hunts as unsupported since the October 6 patch.

Pairing, preferences and consent are preserved. The real Dalamud serializer
upgrade from published 1.0.31.2 passes all serialized-field, OFF/ON preference,
pairing and restart checks. Nothing new is shared, and no setting changes.

- The owner has separately authorized publication.
